Fontes do site: derivadas de TeX Gyre Pagella
==============================================

Os arquivos pagella-regular.woff, pagella-italic.woff, pagella-bold.woff e
pagella-bolditalic.woff são versões derivadas das fontes TeX Gyre Pagella
(GUST e-foundry), distribuídas sob a GUST Font License (texto em
GUST-FONT-LICENSE.txt, que remete à LaTeX Project Public License 1.3c).

Modificações: subconjunto de caracteres latinos (para reduzir o tamanho) e
conversão para o formato WOFF. Os desenhos dos glifos não foram alterados.

Os arquivos foram renomeados (pagella-*.woff), conforme pede a licença para
obras derivadas. Fonte original: https://www.gust.org.pl/projects/e-foundry/tex-gyre
